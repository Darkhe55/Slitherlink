# 数回 Slitherlink

一个基于 Web 的数回（Slitherlink）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

克隆后运行：

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5173`）。

## 游戏规则

在格点之间画线，形成一条闭合环路：

- 每个数字格内的数字，等于围绕它的四条边中被画线的数量
- 环路必须是单一闭合环，不能有分叉或开口
- 棋盘外的 pad 区域不计入数字

## 功能

- **题库**：内置 50+ 道题，从 5×5 入门到 25×25 专家
- **自定义题**：在侧边栏输入任意尺寸和数字，保存为个人题库
- **逻辑解题**：点击"逻辑解题"自动推理，动画展示每一步
- **染色提示**：实时显示环路内外区域（绿色=外侧，橙色=内侧，杂色=未确定）
- **进度保存**：自动保存每道题的进度，刷新不丢失
- **撤销/重做**：完整的操作历史

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- localStorage 存储进度和自定义题库

## 项目结构

```
src/
  main.ts      主逻辑：UI、交互、解题回放
  render.ts    SVG 棋盘渲染
  logic.ts     逻辑解题规则引擎
  coloring.ts  区域染色（内外判断）
  puzzles.ts   题库加载
  puzzles-data.ts  静态题库数据（自动生成）
  state.ts     棋盘状态
  validate.ts  解的合法性校验
```
