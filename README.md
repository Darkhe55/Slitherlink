# 数回 Slitherlink

一个基于 Web 的数回（Slitherlink）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5177/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在格点之间画线，形成一条闭合环路
- 每个数字格内的数字等于围绕它的四条边中被画线的数量
- 环路必须单一闭合，不能分叉或开口

## 操作

| 操作 | 说明 |
|------|------|
| 左键点空格/叉 | 画线 |
| 左键点线 | 清空（正面循环：空、线） |
| 右键点空格/线 | 标叉 |
| 右键点叉 | 清空（负面循环：空、叉） |
| 左键拖动 | 继承左键规则，锁定首次转换源类型 |
| 右键拖动 | 继承右键规则，锁定首次转换源类型 |
| 中键拖动 / 空白处左键拖动 | 平移画布 |
| 滚轮 | 缩放画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **从当前盘面推理**：逻辑解题把玩家已填的标记当作已知前提，回放帧只从当前值出发继续推，不会把已有标记重放成空
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移
- **染色提示**：实时显示环路内外区域（绿色为外侧，橙色为内侧，杂色为未确定）
- **自定义题库**：输入任意尺寸和数字，保存到个人题库，支持编辑和删除；识图导入的题也进入同一题库，可直接编辑/删除


## 逻辑规则引擎（src/logic.ts）

内置逻辑解题器不枚举解，逐步推必然结论并回放，包含：

| 规则 | 内容 |
|------|------|
| 1 | 格数字额度：已满→其余排除；缺口刚好→其余落环 |
| 2 | 数字 1 的角：外边一叉选一 → 内边/对边联动 |
| 3 | 数字 2 的角：外边一叉一环保守 ↔ 对边一叉一环（奇偶） |
| 4 | 数字 3 的角 / 斜角 2-3 传递 |
| 5 | 顶点度数：已 2 环边→余边排除；2 叉 +1 环→剩余落环 |
| 6 | 相邻 1-1：外向边排除 → 共享边排除 |
| 7 | 相邻 3-3：外向边排除 + 各自外侧对边落环；已有外部环边时共享边落环，否则待定 |
| 8 | 染色坍缩探测：某种填法导致内外染色矛盾 → 取另一填法。内置题用完整启发式；自定义小盘面必须再经精确求解复核，大盘面停用，避免启发式误报成片标叉 |
| 9 | 对角 3-3、贴墙 1-2-1 定式 |
| 11 | 线头检测：一步前瞻 + 队列传播，某种填法必然短线头 → 取另一填法（每轮只落一条，连锁交回常规规则） |
| 12 | 环路闭合：已确定环边自身成环 → 其余边全部排除 |
| 13 | 对角 0-3：3 格公共顶点两条内边落环 |
| 14 | 相邻两格计数：nA+nB = 外围环边数 + 2×共享边，推出共享边/外围边 |
| 15 | 二选一同异约束：恰好一条 / 同进同出 用带权并查集传播 |

**审计**（`npm run audit`）覆盖 53 题：所有推理结论与参考解一致、终态均为合法单环解；
规则 8 在内置题上启用完整启发式；自定义/导入题仅在小盘面用精确求解复核后启用，大盘面停用；
其中规则 11（前瞻反证帧）在「前瞻结论立即交回常规规则传播」优化后由 **135 → 18** 帧
（两张无参考解的导入题 12/123 → 1/17）。**逻辑测试**：`npm run logic-test`。
## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 识图导入

```bash
# 预览：自动识别点阵、数字 0–3，并打印数字网格
npm run import-image -- 题板.png

# 写入题库；--verify 会启动本地 solver 校验唯一解（大图可能超时，默认跳过）
npm run import-image -- 题板.png --name "识图 · 40×50" --append --verify
```

- 数字识别优先用内置无衬线字体模板匹配，字体差异大时用字形结构兜底；
- 点阵只接受接近正方形的实心圆点（宽高差 ≤1），数字字形（通常 9×13 等竖长形）不会再被误当成点阵，避免行数翻倍；
- 如果自动映射不对，可人工指定字形簇：`--map 0=3,1=2,4=1`；
- 导入结果写入 `data/library.json`，作为自定义题出现在侧栏，支持“编辑 / ×删除”；
- `--verify` 只做唯一解检查并打印结果，不会把参考解写入题库（导入题仍可求解/逻辑解题）。
